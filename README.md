<h1 align="center">github documentation skills</h1>

<p align="center"><em>Two skills for tighter GitHub READMEs and terse changelogs.</em></p>

## Skills

| Skill | Purpose | skills.sh |
| --- | --- | --- |
| `readme-generator` | Write cleaner READMEs with stronger structure, better Markdown choices, and less filler | [open](https://skills.sh/jasperdevs/github-documentation-skills/readme-generator) |
| `changelog-generator` | Turn commits or release notes into short developer-facing changelog entries | [open](https://skills.sh/jasperdevs/github-documentation-skills/changelog-generator) |

## Install

Install everything first:

```bash
npx skills add jasperdevs/github-documentation-skills --all
```

Install one skill only if you want:

```bash
npx skills add jasperdevs/github-documentation-skills --skill readme-generator
npx skills add jasperdevs/github-documentation-skills --skill changelog-generator
```

## Use

```text
$readme-generator rewrite this repo README so it is tighter, cleaner, and uses tables only where they help
```

```text
$changelog-generator turn the latest release work into a short unreleased section
```
